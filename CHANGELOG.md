# Изменения

## 1.0.0 — 2026-09-14

Первая оформленная учебно-демонстрационная версия.

- Отдельный модуль расчётов Python и точная арифметика JavaScript с общими примерами округления.
- Редактируемые количество, единица измерения и ГОСТ / ТУ; итоговый блок с суммами спецификации.
- Учебный пример из трёх товаров и генератор Excel для проверки импорта.
- Полный экспорт Excel, корректный повторный импорт без строки итогов и без потери количества.
- Повторный расчёт сумм при изменении импортированной цены.
- Проверка входных данных и защита текстовых ячеек от интерпретации как формул.
- Настройки в пользовательской папке, атомарная запись и восстановление структуры повреждённых настроек.
- Локальные ресурсы интерфейса, собственная иконка, подтверждение закрытия и замены таблицы.
- Исправленная сетка объединённых ячеек Word-спецификации.
- README, архитектура, правила расчёта, руководство разработчика, тесты и GitHub Actions.

Публикуются исходники. Установщик и подписанная Windows-сборка не входят в этот релиз.
