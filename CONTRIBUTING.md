# Участие в PyNDS

Проект развивается как компактный учебный пример. Изменение должно решать понятную задачу и оставлять путь от интерфейса до расчёта доступным для изучения.

## Локальная работа

1. Создайте ветку от `main` и виртуальное окружение Python 3.12 или 3.13.
2. Установите `requirements-dev.txt`.
3. Внесите изменение и добавьте проверку поведения, если затронуты расчёты, импорт, экспорт или хранение данных.
4. Выполните команды из раздела «Проверки качества» в README.
5. Откройте pull request с причиной изменения и результатами проверки.

## Договорённости

- Документация и пользовательские сообщения — на русском, имена функций и переменных — на английском.
- Денежные значения Python — `Decimal`, браузерные расчёты — целые числа `BigInt`.
- Правило округления меняется одновременно в обеих реализациях и общих контрольных примерах.
- Ошибки ввода должны быть понятны пользователю и не завершать приложение.
- Примеры содержат только вымышленные товары и организации.
- Исходники не должны зависеть от абсолютных путей разработчика.
- Изменения UI сопровождаются проверкой `scripts/check_ui.py`; скриншоты можно обновить флагом `--screenshots`.

## Сообщение об ошибке

Укажите ОС, Python, действия для воспроизведения и ожидаемый результат. Для ошибок округления приведите точные исходные строки: ставка, цена, количество. Для Excel приложите минимальный обезличенный пример.
